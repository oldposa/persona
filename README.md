# PERSONA — 初期プレビュー

スマホ優先の、外部サービス接続前の操作確認用Webアプリです。HTML/CSS/JavaScriptのみで、ビルドやAPIキーは不要です。

## 動かし方

- `index.html` をブラウザで開くか、GitHub Pages / Cloudflare Pages にこのフォルダのファイルを公開してください。
- GitHub Pagesならリポジトリのルートに3ファイルを置き、Settings → Pages → Deploy from a branch → main / root を選択します。
- GitHub Pages公開時は誰でもサイトを閲覧できます。コード内に個人情報や秘密鍵を入れないでください。

## 現在できること

- マイページの4機能を試す
- 8問の質問に回答し、ブラウザ内に保存
- PERSONAをテキストとして抽出・コピー
- 相手のPERSONAを貼り付けてSTORY用プロンプトを作成
- JSON形式のバックアップ・復元
- MARKETの案内画面

## まだできないこと

- 会員登録、クラウド保存、複数端末同期、販売、決済、購入権限管理
- 個別回答の公開範囲設定、本人確認、相手への安全な共有リンク

**重要:** 保存先はブラウザの localStorage です。ブラウザデータ削除や端末変更で消えるため、必ずバックアップしてください。共有前に回答内容を確認し、機微情報は入力しないでください。

## 今後

操作性を固めてからSupabase（認証・DB）、Cloudflare Workers（サーバー処理）、Stripe Connect（決済）を追加します。
